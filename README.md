# SUPERVISA·PE

Checklist de supervisión en campo de proyectos de inversión del Estado peruano, que funciona sin conexión, y centro de mando para la gerencia.

- **App de campo:** `supervisa_pe.html`, instalable en el celular.
- **Centro de mando:** `centro_mando.html`, para gerente, coordinador y auditor.

Este repositorio contiene **solo el código**. Los datos (proyectos, visitas, fotos y bitácora) se guardan en una base privada protegida por cuentas, roles y reglas por fila. La clave publicable incluida en el código es pública por diseño y no da acceso a ningún dato sin una cuenta activada.
